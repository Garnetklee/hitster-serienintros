# Hitster Serienintros

Musik-Zeitleistenspiel im Stil von Hitster mit 147 Kinderserien-Intros aus dem deutschen Fernsehen (Set `KTV01`).

**▶ Jetzt spielen: https://garnetklee.github.io/hitster-serienintros/**

## So geht's

1. Spieler eintragen, Ziel und Intro-Pool wählen, Spiel starten.
2. Intro anhören, ohne die Serie zu sehen.
3. Karte an die richtige Stelle der eigenen Zeitleiste legen. Es zählt das Jahr der deutschen Erstausstrahlung.
4. Auflösen. Liegt die Karte richtig, bleibt sie. Wer zuerst die Zielzahl an Karten hat, gewinnt.

Gespielt wird auf einem Gerät für alle. Am Handy lässt sich die Seite über „Zum Startbildschirm hinzufügen“ wie eine App ablegen.

## Hinweise

- Die Intros kommen von YouTube, es kann Werbung laufen.
- Privates Fanprojekt, nicht mit Hitster oder Jumbo verbunden.
- Technische Hinweise für die Entwicklung stehen in `CLAUDE.md`, der Hintergrund zum Kartenprojekt in `KONZEPT.md`.
